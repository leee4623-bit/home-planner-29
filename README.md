# 재무플래너

> **앱 주소:** https://leee4623-bit.github.io/home-planner-29/
> 휴대폰에서 열고 안드로이드 ⋮ → **앱 설치**, 아이폰 사파리 공유 → **홈 화면에 추가**.

설계사가 재무계획을 세워 제시하고, 고객이 선택한 뒤 매달 실행을 기록·점검하는 **주거자금 설계 앱**입니다(AFPK 영 플래너 챌린지 2026).
시연 고객은 재무설계 사례 보고서의 **가상 고객 B안**입니다(29세 사무직, 2029-10까지 보증금 4,000만원 + 부대비용 150만원, 비상금 990만원, 신용대출 1,000만원 상환). 모든 금액은 공모전용 가상 사례입니다.

## 쓰는 순서

1. 처음 열면 **나의 재무상태 자가진단** 화면이 나옵니다. 기본정보 · 소득·지출 · 자산·부채 · 재무목표 · 선호·자가진단을 한 페이지에 입력합니다(빈 칸 = 미확인, 0 = 실제 0원, 금액 단위 만원, 칸마다 쉬운 설명과 입력 예시).
   - 위쪽 **[설계 예시 불러오기]**: 공모전 사례 보고서 가상 고객의 설계 *전* 정보를 채웁니다(기준일 2026-11-03 고정).
2. 아래 **[자가진단 완료하고 시작하기]** → 필수값·숫자 범위 확인 → 이 기기에 저장 → 저장에 성공했을 때만 **어떤 화면으로 확인하시겠어요?** 화면으로 넘어갑니다.
3. **[고객 화면으로 들어가기] / [설계사 화면으로 들어가기]**. 두 화면은 같은 고객정보와 계산 결과를 쓰고, 위쪽에 **화면 선택으로 돌아가기 · 고객정보 수정**이 있습니다.
4. 다시 열면 **기존 정보 확인하고 계속하기 / 새 고객 자가진단 시작하기**를 고릅니다. 새 고객을 시작해도 기존 정보는 바로 지우지 않습니다.

## 구성

- **서버·로그인·외부 API·계좌 연동이 없습니다.** 순수 HTML/CSS/JavaScript 정적 앱이고, 데이터는 각자의 브라우저(localStorage)에만 저장됩니다. 기기 사이에 실시간으로 공유되지 않으며, 옮길 때는 더보기 → 데이터 관리의 JSON 내보내기·불러오기를 씁니다.
- 고객용·설계사용 구분은 로그인이 아니라 화면 모드 선택입니다.
- 그래프는 주거자금 진행 · 월 예산 비교 · 설계 전후 목표 비교 세 가지로 단순화했고, 누르거나 마우스를 올리면 값이 보입니다(직접 그린 SVG, 외부 라이브러리 없음).
- 계산은 결정론적 월별 계산(단위 만원)입니다. 확률 표현이나 상품 추천은 하지 않습니다.

## 실행·테스트

```bash
# 그냥 index.html을 더블클릭해도 열립니다(file://). 설치·오프라인은 https 주소에서만.
node --test tests/*.test.js   # Node 22 이상. 폴더만 주는 `node --test tests/`는 Node 22에서 실패
node scripts/sync-docs.js     # 앱 파일을 고친 뒤 GitHub Pages 배포본(docs/)을 다시 만든다
```

GitHub Pages는 main 브랜치의 `/docs` 폴더를 배포합니다. `docs/`는 직접 고치지 말고 위 스크립트로 만듭니다(어긋나면 테스트가 실패합니다).

## 폴더

```
index.html, style.css, sw.js, manifest.webmanifest, icons/   앱
src/            계산 엔진·판정·시나리오·경보·저장·고객정보 입력(순수 함수) + src/ui/ 화면·그래프
data/           demo.js(시연 고객), policies.js(정책상품), products.js(은행 예·적금 비교 후보·출처·확인일)
tests/          정답 테스트(tests/cases.js)와 Node 테스트
scripts/        docs/ 동기화
docs/           GitHub Pages 배포본(자동 생성)
records/        작업 기록·AI 검증 기록·명세 부속 문서
CLAUDE.md       작업 규칙과 계산 명세
```
